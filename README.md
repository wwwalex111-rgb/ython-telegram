# Python Telegram Bot (Demo & Testing Platform)

A lightweight Telegram bot built with **Python** and **aiogram 3.x**. 
This repository serves as a baseline project for testing server deployment, environment variable configuration, and webhook/polling performance on cloud servers.

## Features
- Asynchronous message handling
- Safe configuration via environment variables
- Echo-response system for latency testing

## Deployment Setup
1. Install dependencies: `pip install aiogram`
2. Set your environment variable: `export TELEGRAM_BOT_TOKEN="your_token"`
3. Run the bot: `python main.py`
